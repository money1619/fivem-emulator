# Émulateur FiveM

Émulateur FiveM hors jeu en Lua 5.4 pour tester des ressources (ESX, ox) sans joueur connecté : vrai code serveur et client, natives simulées, horloge virtuelle, réseau par joueur (latence, gigue, perte).

Travail en cours : mocks (ESX, oxmysql, ox_inventory, ox_target), tests et documentation complète arrivent dans les prochains commits.

Exemple rapide : voir `examples/resources/demo_ping`.
